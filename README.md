# 📄 AI Resume Assistant & ATS Analyzer

An AI-powered web application built with **Streamlit** and **Google Gemini API** that helps job seekers analyze their resumes against job descriptions, calculate ATS match scores, identify missing keywords, and automatically rewrite resumes for maximum impact.

🚀 **Live Demo:** [AI Resume Assistant App](https://ai-resume-assistant-app-8te7h9pv3pao7bdioprevw.streamlit.app)

---

## ✨ Features

* **🔍 ATS Resume Analysis:** Evaluates candidate resumes against job descriptions to provide estimated ATS match percentages, key missing keywords, and actionable suggestions.
* **✨ AI Resume Enhancement:** Rewrites and optimizes resumes using strong action verbs, professional formatting, and impact-driven phrasing.
* **📁 Multi-Format Support:** Accepts resumes in PDF and plain text (`.txt`) formats.
* **📥 Multi-Format Downloads:** Export the improved resume seamlessly as either `.txt` or `.pdf`.
* **⚙️ Dynamic Model Selection:** Utilizes Google Gemini LLM models for reliable AI generations.

---

## 🛠️ Tech Stack

* **Frontend & Web Framework:** Streamlit
* **AI Model API:** Google Generative AI (`google-generativeai`)
* **Document Parsing & Generation:** PyPDF, FPDF
* **Deployment Platform:** Streamlit Community Cloud
